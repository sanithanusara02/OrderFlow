# OrderFlow Scope

## Project Goal

Build a real-time food delivery order management system where Customers, Restaurants and Riders stay synchronized through Socket.io.

---

# Priority 1
Implement a server-side order state machine.

- Customer places order
- Restaurant accepts
- Rider assigned
- Rider picks up
- Rider delivers
- Invalid transitions prevented

---

# Priority 2
Synchronize all order changes in real time.

- Customer updates instantly
- Restaurant updates instantly
- Rider updates instantly

---

# Priority 3
Implement simplified rider matching.

- Simulated rider locations
- Nearest rider assignment
- Basic distance calculation

---

# Priority 4
Build a clean demonstration UI.

- Customer page
- Restaurant dashboard
- Rider dashboard
- Live map
